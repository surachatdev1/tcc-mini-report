# รายชื่อสถานศึกษาในฟอร์มประเมิน

ฟอร์มเลือกสถานศึกษาแบบค้นหาได้หลังเลือกจังหวัด โดยใช้ข้อมูลที่ bundle มากับเว็บไซต์ จึงไม่เรียก API ภายนอกและไม่เสีย Firestore read ระหว่างค้นหา

## ขอบเขตข้อมูล

- เฉพาะ 12 จังหวัดดำเนินการตามร่างโครงการ
- โรงเรียนสังกัด สพฐ. จากชุดข้อมูล DMC (`OBEC_SCHOOL_007`)
- โรงเรียนเอกชนในระบบจากสำนักงานคณะกรรมการส่งเสริมการศึกษาเอกชน
- แยกโรงเรียนด้วยรหัสและเก็บชื่อซ้ำที่เป็นคนละโรงเรียน
- มีทางเลือก “กรอกชื่อเอง” สำหรับโรงเรียนสังกัดอื่น โรงเรียนที่เปลี่ยนชื่อ หรือข้อมูลที่ยังไม่ปรับปรุง

ไฟล์ที่เว็บใช้งานจริงคือ `lib/schools.generated.json` ปัจจุบันมี 6,849 แห่ง

## การอัปเดต

```bash
npm run schools:import
npm test
```

ตัวนำเข้าที่ `scripts/import-school-directory.mjs` จะดาวน์โหลดข้อมูลราชการทั้งสองแหล่ง กรอง 12 จังหวัด เรียงชื่อ ตรวจว่าทุกจังหวัดมีข้อมูล และสร้างไฟล์ JSON ใหม่ ห้ามแก้ไฟล์ generated ด้วยมือ

## เหตุผลที่ไม่เรียก API ตอนผู้ใช้ค้นหา

- ผู้ประเมินค้นหาได้ทันทีแม้เครือข่ายช้า
- ไม่มี dependency ต่อ uptime หรือ CORS ของระบบราชการ
- ไม่เกิดค่า Firestore read จาก dropdown
- deploy บน Firebase Hosting แบบ static ได้โดยไม่ต้องมี Cloud Functions

เมื่อข้อมูลต้นทางมี API ที่เสถียรและใหม่กว่านี้ สามารถเปลี่ยนเฉพาะ importer โดยไม่กระทบ component หรือ schema การบันทึกผล

## การคืนชื่อซ้ำและตัวตนโรงเรียน (11 พ.ย. 2569)

คืนโรงเรียน สพฐ. 131 แห่งที่เคยถูกตัดเพราะชื่อซ้ำในจังหวัดเดียวกัน รวม 6,849 แห่ง (สพฐ. 5,417 + เอกชน 1,432) ใช้รหัส `obec-{moeCode}` แยกโรงเรียน ไม่ตัดทิ้งด้วยชื่อ และเก็บอำเภอ ตำบล พร้อมรหัสสถานศึกษา ตัวเลือกค้นหาได้จากชื่อ พื้นที่ หรือรหัส และมีสรุปพื้นที่หลังเลือก

ข้อมูล สพฐ. ยังเป็นชุดข้อมูลปีการศึกษา 2563 การนำเข้าใหม่ไม่ใช่การยืนยันสถานะปัจจุบันของโรงเรียน ส่วนข้อมูลเอกชนคงรายการเดิมจากไฟล์ที่สร้าง 15 ส.ค. 2569 เพราะ URL ต้นทางตอบ redirect วนในวันที่ตรวจสอบ ไม่ได้อ้างว่าดาวน์โหลดรายชื่อเอกชนใหม่สำเร็จ

นำเข้าเฉพาะ สพฐ. โดยรักษาเอกชนเดิมอย่างชัดเจนได้ด้วย:

```bash
node scripts/import-school-directory.mjs --keep-private
# หรือใช้ไฟล์ JSON ที่ดาวน์โหลดจาก OBEC_SCHOOL_007 แล้ว
node scripts/import-school-directory.mjs --obec-file /path/to/obec.json --keep-private
```

โรงเรียนเอกชนที่ไม่มีรหัสราชการในไฟล์จะแสดงเฉพาะพื้นที่และสังกัด ไม่สร้างรหัสราชการสมมติ ตัวนำเข้ารักษา ID เดิม และใช้ ID จากชื่อ+พื้นที่สำหรับรายการเอกชนใหม่แทนลำดับแถว CSV

ใน Firebase production ผลประเมินใหม่ที่เลือกจากทะเบียนเก็บ `school: { id, code, district, subdistrict, source }` คู่กับชื่อและจังหวัด ร่างในเครื่อง รายการ Admin, Dashboard และ Excel ใช้ตัวตนนี้ร่วมกัน รหัสโรงเรียนใน Excel เป็นข้อความเพื่อไม่เสียเลขศูนย์นำหน้า ชื่อที่กรอกเอง/ข้อมูลเดิมไม่มี `school` และไม่ผูกโรงเรียนจากการเดาชื่อ; การนับกลุ่มชื่อเดิมอาจยังไม่ใช่จำนวนสถานศึกษาจริง หากมีชื่อซ้ำต้องยืนยันและแก้ข้อมูลเก่าแยกต่างหาก

ภาพรวมสาธารณะใช้ schema 3 เพื่อแยกโรงเรียนชื่อซ้ำและเผยแพร่พื้นที่ รหัส โดยไม่เพิ่มข้อมูลติดต่อผู้ประเมิน เมื่อ Admin เข้าสู่ระบบ ระบบจะสร้าง snapshot ใหม่หากยังเป็น schema เก่า; ตัวอ่านยังรองรับ snapshot schema 1/2 ระหว่าง deploy
