# รายชื่อสถานศึกษาในฟอร์มประเมิน

ฟอร์มเลือกสถานศึกษาแบบค้นหาได้หลังเลือกจังหวัด โดยใช้ข้อมูลที่ bundle มากับเว็บไซต์ จึงไม่เรียก API ภายนอกและไม่เสีย Firestore read ระหว่างค้นหา

## ขอบเขตข้อมูล

- เฉพาะ 12 จังหวัดดำเนินการตามร่างโครงการ
- โรงเรียนสังกัด สพฐ. จากชุดข้อมูล DMC (`OBEC_SCHOOL_007`)
- โรงเรียนเอกชนในระบบจากสำนักงานคณะกรรมการส่งเสริมการศึกษาเอกชน
- ตัดชื่อซ้ำภายในจังหวัดเดียวกันด้วยชื่อที่ normalize แล้ว
- มีทางเลือก “กรอกชื่อเอง” สำหรับโรงเรียนสังกัดอื่น โรงเรียนที่เปลี่ยนชื่อ หรือข้อมูลที่ยังไม่ปรับปรุง

ไฟล์ที่เว็บใช้งานจริงคือ `lib/schools.generated.json` ปัจจุบันมี 6,718 แห่ง

## การอัปเดต

```bash
npm run schools:import
npm test
```

ตัวนำเข้าที่ `scripts/import-school-directory.mjs` จะดาวน์โหลดข้อมูลราชการทั้งสองแหล่ง กรอง 12 จังหวัด เรียงชื่อ ตรวจว่าทุกจังหวัดมีข้อมูล และสร้างไฟล์ JSON ใหม่ ห้ามแก้ไฟล์ generated ด้วยมือ

## เหตุผลที่ไม่เรียก API ตอนผู้ใช้ค้นหา

- ผู้ประเมินค้นหาได้ทันทีแม้เครือข่ายช้า
- ไม่มี dependency ต่อ uptime หรือ CORS ของระบบราชการ
- ไม่เกิดค่า Firestore read จาก dropdown
- deploy บน Firebase Hosting แบบ static ได้โดยไม่ต้องมี Cloud Functions

เมื่อข้อมูลต้นทางมี API ที่เสถียรและใหม่กว่านี้ สามารถเปลี่ยนเฉพาะ importer โดยไม่กระทบ component หรือ schema การบันทึกผล
