## กติกาคะแนน

1. คะแนน 0 = ไม่มีข้อมูลหรือเอกสาร จึงไม่สามารถประเมินได้ และนับเป็น 0 ในสูตร ไม่ใช่ N/A
2. คะแนน 1 = ขั้นพื้นฐาน, 2 = ขั้นมาตรฐาน, 3 = ขั้นยกระดับ
3. คะแนนหมวด = ผลรวมคะแนนข้อในหมวด / (จำนวนข้อในหมวด × 3) × 100
4. คะแนนรวม = ผลรวมของ (คะแนนหมวด × น้ำหนักหมวด / 100)
5. A ≥ 85, B ≥ 70 และ < 85, C ≥ 50 และ < 70, D < 50
6. ต้องเลือกคะแนนครบทุกข้อ ส่วนเหตุผลและข้อมูลประกอบเป็นทางเลือกตาม requirement ล่าสุด
7. ข้อที่ได้ 0–1 จัดเป็นประเด็นควรพัฒนาเพราะยังไม่ถึงขั้นมาตรฐาน 2 คะแนน โดยแสดงคำแนะนำแยกรายข้อ
8. เซิร์ฟเวอร์คำนวณคะแนนซ้ำจากคำตอบ ไม่รับคะแนนรวมจาก client

## การใช้ผล

- ใช้เพื่อสะท้อนช่องว่าง วางแผนพัฒนา และเสนอการสนับสนุนเชิงนโยบาย
- ไม่ใช้ลงโทษ ตัดสิน หรือตัดงบประมาณ
- ผลสถานศึกษาและผลหน่วยงานกำกับต้องแยกบริบทการแปลผล แม้ใช้ช่วง A–D เดียวกัน
- Dashboard แสดงข้อมูลรวมเป็นหลัก และใช้คะแนน 0–1 เพื่อจัดลำดับประเด็นที่ควรสนับสนุน
- ชื่อ ตำแหน่ง และเบอร์โทรเป็นข้อมูลอ้างอิงภายใน แสดง/ส่งออกเฉพาะ Admin เจ้าของโครงการหรืออีเมล Viewer ที่ได้รับสิทธิ์เป็นรายบุคคล
- หลังส่งผล ผู้ตอบเห็นกราฟคะแนนรายหมวดและตำแหน่งเทียบค่ากลางของกลุ่ม โดยเผยแพร่ค่ากลางเฉพาะกลุ่มที่มีอย่างน้อย 10 ผลประเมิน

## ประเด็นในร่างที่ต้องให้เจ้าของเกณฑ์ยืนยันก่อน Production

1. เกณฑ์รถรับส่งเรื่องใบรับรองแพทย์มีข้อความ “ตรวจมาแล้วไม่น้อยกว่า 6 เดือน” แต่หลักฐานระบุ “ใบรับรองแพทย์ไม่เกิน 6 เดือน” ซึ่งมีความหมายตรงข้าม ระบบยังคงข้อความตารางต้นฉบับและต้องรอเจ้าของเกณฑ์ยืนยันคำที่ถูกต้อง
2. ภาคผนวกบทที่ 4 ย่อหน้าแรกกล่าวถึงรถจักรยานยนต์และหมวกกันน็อก ทั้งที่หัวข้อและตารางเป็นการดำเนินงานตามมติ ครม. ระบบยึดหัวข้อและตารางบทที่ 4 เป็นหลัก
3. ข้อ 4.2 แสดงรายชื่อ 3 หน่วยงาน แต่ตารางข้อ 4.3 มี อปท. เพิ่มเป็นหน่วยงานที่ 4 ระบบรวม อปท. ตามตารางเกณฑ์และน้ำหนัก
4. เอกสารเจตนารมณ์กล่าวถึงหลักฐานแนบ แต่ requirement ภาพให้เอาหน้าแนบหลักฐานออก เดโมจึงแสดงรายการหลักฐานที่ควรตรวจดูแต่ยังไม่รับไฟล์ ต้องยืนยัน workflow การตรวจหลักฐานก่อน Production
