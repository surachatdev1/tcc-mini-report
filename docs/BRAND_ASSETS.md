# Brand assets

ระบบแสดงตราสภาองค์กรของผู้บริโภค (TCC) และตราสำนักงานกองทุนสนับสนุนการสร้างเสริมสุขภาพ (สสส.) คู่กันในส่วนหัว โดยแยกพื้นที่ของแต่ละตราและรักษาสัดส่วนเดิม ไอคอนแท็บและไอคอนบนอุปกรณ์พกพายังคงใช้ตรา สสส. เพียงตราเดียวเพื่อให้มองเห็นชัดในขนาดเล็ก

## แหล่งอ้างอิง

- คู่มืออัตลักษณ์ต้นทาง: `https://www.thaihealth.or.th/wp-content/uploads/2022/10/ThaiHealth-Brand-Portfolio_250722.pdf`
- ไฟล์เวกเตอร์ที่ถอดจากคู่มืออัตลักษณ์: `https://commons.wikimedia.org/wiki/File:Emblem_of_the_Thai_Health_Promotion_Foundation.svg`
- หน้าอ้างอิงตรา TCC: `https://www.tcc.or.th/document-category/announcement/`
- ไฟล์ WebP ที่ใช้ในส่วนหัว: `public/images/tcc-office-logo.webp` และ `public/images/thaihealth-logo.webp`
- ไฟล์ไอคอน: `public/favicon.ico`, `public/favicon-32x32.png`, `public/apple-touch-icon.png`, `public/icon-192.png` และ `public/icon-512.png`

ไฟล์ในระบบคงสี สัดส่วน และองค์ประกอบเดิม ไม่เติมข้อความหรือดัดแปลงตรา กรอบตราคู่ใช้พื้นหลังสีขาว มีเส้นคั่นกลาง และมีพื้นที่ว่างรอบตราเพื่อไม่ให้ส่วนประกอบถูกตัดเมื่อแสดงบนอุปกรณ์ต่าง ๆ

ห้ามนำตราไปยืด บีบ เปลี่ยนสี ตัดองค์ประกอบ หรือใส่เอฟเฟกต์ที่ทำให้อัตลักษณ์ต่างจากต้นฉบับทางการ
